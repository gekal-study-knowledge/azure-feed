### Python support has arrived in the guided Copilot experience for VS Code

- **Link**: [https://techcommunity.microsoft.com/t5/apps-on-azure-blog/python-support-has-arrived-in-the-guided-copilot-experience-for/ba-p/4572591](https://techcommunity.microsoft.com/t5/apps-on-azure-blog/python-support-has-arrived-in-the-guided-copilot-experience-for/ba-p/4572591)
- **Published**: 2026-11-12 01:56:47
- **Fetched**: 2026-11-12 13:34:40

<details class="entry-summary">
<summary>詳細を表示</summary>
<p>When we introduced the&nbsp;<a href="https://techcommunity.microsoft.com/blog/AppsonAzureBlog/introducing-a-guided-copilot-experience-for-building-azure-apps-in-vs-code/4557120" rel="noopener" target="_blank">guided Copilot experience for building Azure apps in VS Code</a>, we started with JavaScript and TypeScript, with Python on the roadmap. Since then, we've seen people creating Python projects with the experience, and we wanted to make sure our Python lovers had proper support.</p>
<p>Today, we're excited to announce that the guided Copilot experience in VS Code now fully supports Python projects. 🐍</p>
<h2>From Python idea to Azure app</h2>
<p>The guided experience helps you move from an idea to a deployed Azure app through a structured workflow, with checkpoints for reviewing important decisions. Now Python developers can use that same experience to:</p>
<p>&nbsp;</p>
<img />
<p>&nbsp;</p>
<ol>
<li><strong>Plan and scaffold:</strong> Describe your app, review the proposed architecture, and approve a plan before code is generated.</li>
<li><strong>Develop locally:</strong> Get help preparing your development environment, then run and iterate on your Python project in VS Code.</li>
<li><strong>Deploy to Azure:</strong> Review the deployment tools, resources, and estimated costs before deploying your app.</li>
</ol>
<p>This guided path complements the free-form Copilot workflows you already know, so you can choose the approach that works best for you.</p>
<h2>Give it a try</h2>
<p>Install the <a href="https://marketplace.visualstudio.com/items?itemName=ms-vscode.vscode-node-azure-pack" rel="noopener" target="_blank">Azure Tools extension pack</a>, open an empty folder in VS Code, and start the guided Copilot experience with your Python project in mind.</p>
<p>Whether you're building an API, prototyping an idea, or learning something new, we'd love to see what you create. Have feedback? <a href="https://github.com/microsoft/vscode-azureresourcegroups/" rel="noopener" target="_blank">Share it with us on GitHub</a>.</p>
<p>Thanks to everyone who's been building Python projects with the experience. We're excited to see what you make next!</p>
</details>
