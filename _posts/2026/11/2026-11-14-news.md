## Apps on Azure Blog

### Introducing Azure Container Apps Sandboxes in Visual Studio Code

- **Link**: [https://techcommunity.microsoft.com/t5/apps-on-azure-blog/introducing-azure-container-apps-sandboxes-in-visual-studio-code/ba-p/4573296](https://techcommunity.microsoft.com/t5/apps-on-azure-blog/introducing-azure-container-apps-sandboxes-in-visual-studio-code/ba-p/4573296)
- **Published**: 2026-11-14 04:44:47
- **Fetched**: 2026-11-14 20:50:02

<details class="entry-summary">
<summary>詳細を表示</summary>
<p>We're introducing support for&nbsp;<strong>Azure Container Apps Sandboxes in the Azure Container Apps extension for Visual Studio Code</strong>. The new experience brings sandbox groups and individual sandboxes into the Azure Resources view, putting everyday sandbox operations alongside your development workflow.</p>
<p>Instead of switching tools to create and manage sandbox resources, you can work with them directly in VS Code, see their current state, and follow operation results in the Azure output channel.</p>
<h2>Your sandboxes, alongside your code</h2>
<p>The new <strong>Container Apps Sandboxes</strong> node gives sandbox resources a dedicated home in the Azure Resources tree. Expand a sandbox group to find its sandboxes and see status labels such as <strong>Running</strong> and <strong>Stopped</strong>.</p>
<p>Start with <strong>Create Sandbox Group...</strong> and follow the guided workflow, including choosing an existing resource group or creating a new one. Once your sandbox group appears in the tree, right-click it and select <strong>Create Sandbox...</strong> to create a sandbox within that group.</p>
<p>The result is a straightforward path from creating a group to working with a running sandbox, all from your editor.</p>
<h2>Execute commands without switching tools</h2>
<p>With <strong>Execute Command in Sandbox...</strong>, you can run a command against a sandbox directly from VS Code. This brings command execution into the same resource-management experience you use to find and inspect your sandboxes.</p>
<p>&nbsp;</p>
<img />
<p class="lia-align-center"><em>Enter a command to run in the sandbox without leaving VS Code.</em></p>
<p>The Azure output channel reports operation results, helping you keep track of what happened without leaving the editor.</p>
<h2>Create named snapshots</h2>
<p>Use <strong>Snapshot Sandbox...</strong> to create a named snapshot of a sandbox. Snapshot creation is available alongside the other sandbox actions, so you can create a snapshot as part of your workflow rather than switching to a separate management tool.</p>
<p>&nbsp;</p>
<img />
<p class="lia-align-center"><em>Give your snapshot a name directly in the editor.</em></p>
<h2>Stop and resume from the resource tree</h2>
<p>Sandbox lifecycle controls are available directly in the extension:</p>
<ul>
<li><strong>Stop Sandbox</strong> to stop a running sandbox.</li>
<li><strong>Resume Sandbox</strong> to resume a stopped sandbox.</li>
<li><strong>Delete Sandbox</strong> to remove a sandbox you no longer need.</li>
</ul>
<p>Inline status labels make it easy to see the transition between running and stopped states. Operation results also appear in the Azure output channel.</p>
<p>&nbsp;</p>
<img />
<p class="lia-align-center"><em>Access sandbox actions from the resource tree.</em></p>
<p>Sandbox groups include familiar management actions such as <strong>Edit Tags...</strong>, <strong>View Properties</strong>, <strong>Open in Portal</strong>, and <strong>Refresh</strong>, as well as an option to delete a sandbox group.</p>
<h2>Get started</h2>
<p>To explore the new experience:</p>
<ol>
<li>Install or update the <a href="https://marketplace.visualstudio.com/items?itemName=ms-azuretools.vscode-azurecontainerapps" target="_blank">Azure Container Apps extension</a> to a release that includes Sandbox support, then sign in to Azure.</li>
<li>Open the Azure Resources view and find <strong>Container Apps Sandboxes</strong> under your subscription.</li>
<li>Use <strong>Create Sandbox Group...</strong> and follow the prompts to create a group.</li>
<li>Right-click the group and select <strong>Create Sandbox...</strong>.</li>
<li>Explore command execution, named snapshots, and stop/resume controls from your sandbox's available actions.</li>
</ol>
<p><strong>Less context switching. More time in your development workflow.</strong> Azure Container Apps Sandbox support brings creation and day-to-day management into VS Code, right where you're already working.</p>
<p>Have feedback? Share it in the <a href="https://github.com/microsoft/vscode-azurecontainerapps/issues" target="_blank">Azure Container Apps extension repository</a>.</p>
</details>
