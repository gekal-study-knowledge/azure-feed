<p><strong>What's New</strong></p>
<p><strong>Security Insights:&nbsp;</strong></p>
<img />
<p>&nbsp;</p>
<p>The new Security page in Kubernetes Center gives you an immediate, all clusters or Kubernetes Fleet Manager-wide view of your security posture without leaving the portal.</p>
<p>At the summary level you can see:</p>
<ul>
<li><strong>Security vulnerabilities</strong> broken down by risk level</li>
<li><strong>Runtime alerts</strong>&nbsp;categorized by severity</li>
<li><strong>Non-compliant regulatory standards</strong>, with visibility into which benchmarks your clusters are falling short on</li>
</ul>
<p>Drilling deeper into the security detail view exposes four distinct panels:</p>
<p><strong>Security Vulnerabilities</strong> show a total count of vulnerabilities across all clusters, broken down by risk tier.</p>
<p><strong>Runtime Alerts</strong> surfaces live alerts from Defender for Containers categorized by High, Medium, Low, and Informational severity. You can see at a glance whether any active threats require immediate attention, and drill into the full alert list with one click.</p>
<p><strong>Misconfigurations</strong> show a count of configuration issues detected across your clusters, again broken down by risk level.</p>
<p><strong>Regulatory Compliance Standards</strong> lets you see which compliance standards your clusters are enrolled in, which are passing, and which are failing. The view surfaces the lowest-performing standard with its pass rate, so you know exactly where to focus remediation effort.</p>
<p><strong>Recommendations</strong> are shown alongside these panels, providing actionable and prioritized guidance. Each recommendation shows affected resource counts and links directly to remediation details.</p>
<p><strong>Note: Security insights require Microsoft Defender for Containers to be enabled. Kubernetes Center will confirm at a glance whether all your clusters have it enabled.</strong></p>

<p><strong>FAQ</strong></p>
<p><strong>Do I need Microsoft Defender for Containers enabled to use the security features?</strong> Yes. Security vulnerabilities, runtime alerts, and misconfiguration data are powered by MS Defender for Containers. Kubernetes Center will show you if any clusters don't have it enabled so you can quickly close that gap.</p>
<p><strong>Does this work across all my subscriptions and clusters?</strong> Kubernetes Center aggregates data across all AKS clusters you have access to. Make sure you have the appropriate RBAC permissions across the subscriptions you want visibility into.</p>
<p><strong>What is LTS and should I enable it for eligible clusters?</strong> Long Term Support (LTS) extends the supported lifecycle of a Kubernetes version beyond its standard window. It's available for clusters on eligible versions running the Premium tier. If you have clusters showing "Out of support, LTS eligible," enabling LTS is the fastest way to restore support coverage while you plan a full version upgrade.</p>
<p><strong>Is there a cost to use Kubernetes Center?</strong> Kubernetes Center itself is part of the Azure portal experience and there is no additional charge. Note that Microsoft Defender for Containers, which powers the security features, is a paid add-on. See the <a class="lia-external-url" href="https://azure.microsoft.com/pricing/details/defender-for-cloud/" rel="noopener" target="_blank">Defender for Containers pricing page</a> for details.</p>
<p><strong>Where can I learn more about the Kubernetes version lifecycle?</strong> See the <a class="lia-external-url" href="https://learn.microsoft.com/azure/aks/supported-kubernetes-versions" rel="noopener" target="_blank">AKS Kubernetes version support policy documentation</a> for full details on version support windows, LTS eligibility, and upgrade guidance.</p>
