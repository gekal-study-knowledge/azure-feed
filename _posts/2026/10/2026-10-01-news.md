## Azure Status

### Active - Multiple services experiencing connectivity issues in multiple regions

- **Link**: [https://azure.status.microsoft/en-us/status/](https://azure.status.microsoft/en-us/status/)
- **Published**: 2026-10-01 05:30:00
- **Fetched**: 2026-10-01 08:15:57

<div class="entry-summary">
<p>Starting at 20:30 UTC on 30 September 2026, customers using ExpressRoute and/or VPN Gateway may experience degraded or interrupted network connectivity. Customers may also experience failures or delays when performing some network management operations.</p><p><strong>Current status:</strong> We have paused the infrastructure servicing activity associated with the onset of this event, preventing additional resources from entering the affected servicing workflow. We are seeing continued recovery across impacted ExpressRoute gateways and are monitoring this recovery to confirm that it remains durable.</p><p>For VPN Gateway, some affected gateways have experienced reduced redundancy rather than a complete loss of connectivity. Recovery continues to be monitored.</p><p>Some supporting network management components have not recovered automatically and are contributing to management operation failures in a subset of affected regions. Engineering teams are actively restoring these components using alternate healthy instances where available.</p><p>Our investigation continues to show a correlation between this event and infrastructure operating system servicing activity. However, the underlying failure mechanism has not yet been confirmed. We are investigating why some network service instances became unhealthy and why recovery behavior has differed between services.</p><p>We will provide additional information within the next 30 minutes, or sooner if events warrant.</p>
</div>

### Network security perimeter metrics are now generally available in Public Cloud

- **Link**: [https://techcommunity.microsoft.com/t5/azure-networking-blog/network-security-perimeter-metrics-are-now-generally-available/ba-p/4561244](https://techcommunity.microsoft.com/t5/azure-networking-blog/network-security-perimeter-metrics-are-now-generally-available/ba-p/4561244)
- **Published**: 2026-10-01 04:35:03
- **Fetched**: 2026-10-01 18:30:18

<details class="entry-summary">
<summary>詳細を表示</summary>
<img />
<p>We are excited to announce the&nbsp;<strong>general availability (GA) of network security perimeter metrics</strong>, a capability that helps administrators monitor network access patterns, understand the impact of the access rules, and identify unexpected traffic behaviour across protected resources. These metrics are available through Azure Monitor and can be used to create dashboards, alerts, and operational monitoring experiences.</p>
<p><strong>Why use network security perimeter metrics?</strong></p>
<p>Network security perimeter metrics capture access requests evaluated by the data plane and provide visibility into network activity associated with the perimeter-protected resources. Metrics enable monitoring scenarios such as:</p>
<ul>
<li>Tracking approved and denied access requests.</li>
<li>Monitoring inbound and outbound access activity.</li>
<li>Understanding traffic patterns across protected resources, profiles, access modes and access rule versions.</li>
<li>Detecting unexpected access attempts.</li>
<li>Validating the impact of access rules’ changes.</li>
<li>Establishing a baseline before moving a perimeter from Transition mode to Enforced mode.</li>
</ul>
<p>Network security perimeter metrics render aggregated time-series data that is optimized for monitoring, alerting, and trend analysis.</p>
<p><strong>Accessing network security perimeter metrics</strong></p>
<p>Network security perimeter metrics are available through Azure Monitor.</p>
<ol>
<li>In the Azure portal, navigate to your network security perimeter resource.</li>
<li>Select <strong>Metrics</strong> under the <strong>Monitoring</strong> section.</li>
<li>‘Add Metric’</li>
<li>Choose the ‘NSP access metrics’ namespace.</li>
<li>Select a metric and configure filters, splitting as needed.</li>
<li>Use Azure Monitor features to build charts, dashboards, workbooks, and metric alerts.</li>
<li>Multiple charts may be created for different metrics that are intended to be monitored.</li>
</ol>
<p>Regular Azure Monitor features like drilling into the logs, saving the chart as a dashboard or exporting it to a workbook can also be performed.</p>

<p>While metrics and diagnostic logs are complementary monitoring tools, metrics provide a high-level operational view and support alerting, while diagnostic logs provide detailed event data for troubleshooting and investigation.
